## 一句話總結

一個**最傳統的回合制地城遊戲**原型：C++ 寫核心邏輯、Godot 做畫面。
目前剛把回合系統「打掉重練」成最乾淨的版本，**能跑、有測試、狀態穩定**。

---

## 這是什麼專案

- 名字：gamecore-zone（三層架構裡的「區域層」）。
- 玩法：在地圖上走動、撞怪攻擊、撿補品、下樓梯——經典 roguelike 的基本盤。
- 技術分兩半：
  - **核心（C++）**：純邏輯，不依賴遊戲引擎，方便測試。
  - **前端（Godot 4.6）**：負責畫面和按鍵，透過外掛（GDExtension）接到核心。

---

## 目前進度到哪裡

### ✅ 已經做好、能用的

| 功能 | 狀況 |
|------|------|
| **回合制引擎**（TurnEngine） | 按一鍵 = 英雄走一步 + 所有怪物各動一次。剛重構完，最精簡乾淨。 |
| **移動／攻擊** | 八方向移動；走進有怪的格子就是攻擊（沒有獨立攻擊鍵）。 |
| **怪物 AI** | 最簡單的「追著英雄跑」，貼到身邊就打。 |
| **撿道具** | 走過補血藥水自動撿、自動回血。 |
| **下樓梯** | 踩到樓梯換下一層。 |
| **視野（FOV）** | 算出英雄能看到哪些格子。 |
| **存讀檔** | F5 存、F9 讀，整個遊戲狀態能完整存回來。 |

### 🧪 品質驗證

- C++ 單元測試：**29 個測試 / 93 個檢查點，全綠。**
- Godot 端到端跑一遍：**通過（VERIFY PASSED）。**

### 🧹 這次重構做了什麼

把之前一套比較複雜的實驗系統（能量排程、技能、詠唱、持續傷害）**整套移除**，淨刪約 1300 行，
換成「教科書式」的最簡回合制當作乾淨地基。簡單講就是：**先把地基打穩，複雜功能以後再加。**
