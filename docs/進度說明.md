# 專案進度說明

> 最後更新：2026-07-19

## 一句話

C++20/EnTT ECS 核心 + Godot 4.6 GDExtension 前端，跑兩個平行獨立的遊戲原型：**傳統回合制地城探索**與 **SRPG 戰棋戰鬥**。兩者共用 ECS 基建但回合驅動獨立。

## 已落地（兩條線）

### 地城探索

| 功能 | 現況 |
|------|------|
| TurnEngine 回合制 | 精簡版，按一鍵 = 英雄走一步 + 全 NPC 行動一輪 |
| 撞擊攻擊 | 走進有怪物的格 = 攻擊，無獨立攻擊鍵 |
| NPC AI（decide_npc） | LOS 警覺／記憶／追擊／徘徊，純函式 |
| 道具拾取 | 走過補血藥水自動撿 |
| 下樓梯 | 踩到樓梯換層，勝利條件 = 第 5 層 |
| FOV | Bresenham 視野計算 |
| 存讀檔 | F5/F9，cereal 序列化 registry |
| 圖塊渲染 | Kenney 1-Bit Pack，霧中戰爭調暗 |
| HUD/訊息列 | HP 條、訊息列、除錯面板（Tab） |
| 可重現亂數 | 固定 seed 整場重現 |
| headless 驗證 | BFS 機器人殺向樓梯，斷言必達結局 |

### SRPG 戰棋

| 功能 | 現況 |
|------|------|
| ActionBar 行動值 | ToME4 模型，kCtToAct=1000，溢出保留不歸零 |
| 可達集 | 四方向 BFS，牆+單位佔格阻擋 |
| 單位回合子狀態機 | 移動一次 + 行動一次，攻擊即結束 |
| 敵方 AI（decide_tactics） | 射程內打最脆目標，遠程不送頭（第二鍵 nearest 越大越好） |
| 敵方 AI 完整打完整場 | 22 case 測試全綠 |
| TacticsBattle橋樑 | 20×14 競技場，雙方各 3 單位原型 |
| 主選單 main_menu.tscn | 選地城探索 / 戰棋對戰 |
| headless 驗證 | 機器人打完整場，斷言 events 覆蓋移動/攻擊/死亡 |

### 測試現況

- doctest：**55 case / 236 assertion** 全綠
- headless verify.gd：**VERIFY PASSED**
- headless verify_tactics.gd：**TACTICS VERIFY PASSED**
- 使用者桌面實測兩場景 OK

### 還沒收尾

- **戰棋數值未調校**：單位原型數值（戰士 18/5、弓手 11/4、斥候 13/3）和競技場參數（WALL_PCT=12）是隨手初值
- **本地 main 有 10 個未 push commit**：回合重構、可玩化、SRPG 戰棋三個 slice
- **戰棋後續主題明確不在已落地範圍**：職業/裝備/地形效果/命中率/反擊/技能/增援/戰中存讀檔——這些是新工作，非 bug
