# CI 構想

> 日期：2026-06-11
> 定位：用最小成本建立回歸護欄，先保 core，再接 Godot headless。

---

## 1. 第一階段：core ctest（優先序：高）

GitHub Actions job：

```text
checkout
configure cmake
build zone_tests
ctest --output-on-failure
```

先跑 Ubuntu。Windows / macOS 等專案穩定後再補。

## 2. 快取

cache key 包含：

- compiler
- CMakeLists hash
- dependency lock / godot-cpp commit

doctest 這類小依賴快取價值低，不必過度設計。

## 3. 第二階段：Godot headless（中）

難點是取得固定 Godot binary 與建置 GDExtension。可選：

- 使用官方 release zip。
- cache Godot binary。
- build extension 後跑 `verify.gd`。

這個 job 可先設 manual 或 nightly，避免每次 push 都太慢。

## 4. PR 檢查分層

- 必跑：format/build/ctest。
- 可選：headless verify。
- 夜間：simulation 多 seed、benchmark。

## 5. 不做的事

- 不一開始就追求全平台矩陣。
- 不讓 CI 下載未鎖版依賴。
- 不把 benchmark 當 PR gate；效能波動容易製造噪音。
