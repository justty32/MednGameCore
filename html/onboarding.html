最重要的心智模型

兩套刻意分離的回合系統

改東西前先確認自己在哪個模組。混在一起是最常見的認知陷阱。

地城探索

TurnEngine + 撞擊攻擊

  • 回合序=加入序，英雄最先。begin_round() → step() 到 RoundDone。
  • 無獨立攻擊：移動進有 actor 的格 = 攻擊。
  • NPC：decide_npc（LOS 警覺+記憶、相鄰即攻）
  • 勝利 = 第 5 層樓梯。每層成長，否則數學上打不贏。
核心：src/core/turn/
戰棋戰鬥

ActionBar + 單位子回合

  • ToME4 行動值：kCtToAct=1000，溢出保留，快角可連動。
  • 可達集 = 四方向 BFS，牆+單位佔格皆阻擋。
  • 單位回合 = 移動一次 + 行動一次，攻擊即結束。
  • AI：射程內打最脆，進射程就停（遠程不送頭）。
核心：src/core/tactics/

別踩的坑

01 無上限 -j 會炸機器

任何 cmake --build 都加 -j4。541 個編譯程序吃 60GiB RAM 的 OOM 會強制重啟。

02 TurnEngine 不是佔位品

2026-06-21 重構後收斂成傳統回合制是設計目標。行動值排程另開 tactics/，不得加回 TurnEngine。

03 新增 component 必改 all_components.h

否則存檔悄悄漏掉該 component，無編譯警告無 runtime crash。

04 核心不得認識 Godot

#include <godot_cpp> 只能出現在 gbind/。core 沾到就破壞了可單元測試的地基。
