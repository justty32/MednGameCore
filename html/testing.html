測試與驗證

三層驗證：單元測試 → headless → 實機

① doctest（純 C++，不需 Godot）→ ② Godot headless（地城+戰棋各一）→ ③ 開視窗自己玩。

建置鐵律：一律 -j4（或更低） 曾因無上限 -j 同時起約 541 個編譯程序耗盡 60 GiB RAM 觸發 OOM 強制重啟——本專案第一鐵律。

第一層 · 最快

① 純 C++ 單元測試

不需 Godot。涵蓋地城 TurnEngine/apply_action/decide_npc 與戰棋 ActionBar/可達集/子狀態機/AI。

# 先建核心 zone_core，再建並跑 tests（find/link 已建好的 zone_core）
$ cmake -S projects/core -B projects/core/build
$ cmake --build projects/core/build -j4
$ cmake -S projects/tests -B projects/tests/build
$ cmake --build projects/tests/build -j4
$ ./projects/tests/build/bin/zone_test
# 或
$ ctest --test-dir projects/tests/build --output-on-failure

預期：55 測試案例 / 236 斷言 · 全綠。 過濾子集：--test-case="*turn_engine*"、--test-case="*tactics*"。

第二層 · 端到端

② Godot headless 驗證

載入原生擴充 libzone_gd.so，驗證 C++ ↔ Godot 整條接線。

$ cmake -S projects/core -B projects/core/build -DZONE_BUILD_GDEXTENSION=ON
$ cmake --build projects/core/build --target zone_gd -j4
# 首次需 --import
$ godot-mono --headless --path projects/godot_zone --import
# 地城：BFS 機器人殺向樓梯
$ godot-mono --headless --path projects/godot_zone -s res://verify.gd
# 戰棋：機器人打完整場
$ godot-mono --headless --path projects/godot_zone -s res://verify_tactics.gd

預期：VERIFY PASSED / TACTICS VERIFY PASSED

綠燈也要看它驗什麼 早期 verify.gd 曾在指令從沒執行的情況下顯示通過。現版用真正推進回合的 BFS 機器人斷言英雄移動+掉血才算數。

第三層

③ 開視窗操作

$ godot-mono --path projects/godot_zone

main scene = main_menu.tscn，選地城或戰棋。

地城按鍵

按鍵動作
WASD / 方向鍵 / KP1-9八方向移動（英雄+整輪 NPC）
按住方向鍵0.5 秒後每 0.08s 自動走；遇牆/攻擊/下樓/新敵中斷
. / KP5等待
R重開
F5 / F9存檔 / 讀檔
