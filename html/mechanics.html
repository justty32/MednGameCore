機制詳解

兩套回合系統怎麼運作

地城（TurnEngine）與戰棋（ActionBar/Battle）不共用、不互相依賴。 共用只有 ECS/地圖/存讀檔基建。改任何一邊前先確認在哪個模組。

地城 · 核心

TurnEngine：一輪怎麼跑

std::list<entt::entity>，順序＝加入序（hero 最先）。begin_round() → 反覆 step(ctx) 直到 RoundDone。

概念內容
actor list加入序=行動序。remove_actor 安全處理 cursor，死亡才移除
act_point首次輪到時 ActPointComponent 設 1000，動完歸 0（為未來多次行動預留）
ControllerComponent 分派Player → WaitingPlayer 阻塞等 submit()；Self/Faction → 立即 decide() + resolve()
EngineCtxregistry& + decide/resolve/trace 三個 callback，引擎不持 registry
Action{Idle, Move, Wait}。無 Attack/技能/詠唱。Move param = 方向編碼

地城 · 結算

apply_action

把 Action 落地到世界。沒有獨立攻擊指令——移動進有 actor 的格 = 攻擊。

情況結果事件
Move → 撞牆/出界停住BumpedWall
Move → 撞 actor（致死）扣攻擊力傷害ActorDied
Move → 撞 actor（未死）扣傷害BumpedActor
Move → 空格（踩道具）移動，自動拾取ItemPickedUp
Move → 下樓梯移動，觸發下樓ReachedStairDown
Wait/Idle消耗回合—
死亡不在此 destroy 被殺目標只發事件，由呼叫端統一從 registry/actor list 移除，避免迭代失效。

地城 · AI

decide_npc

純決策函式，吃 world 回傳 Action。唯一副作用：更新 NpcAiComponent 警覺狀態。放在 core 可直接 doctest。

NpcAiConfig{ sight_radius=10, alert_memory=6 }
1 更新警覺：LOS + sight_radius 看得到 → 警覺；看不到則 alert_turns 遞減到期解除 2 已警覺且相鄰 → 撞擊攻擊（不受 move_chance 閘門） 3 擲 move_chance 不過 → Wait 4 已警覺 → 追擊：大 delta 軸優先，受阻換軸 5 未警覺 → 四方向隨機徘徊

舊的 decide_chase / npc_ai_system 都已刪除，只剩這一套。

戰棋

SRPG 戰棋（平行系統）

以下全在 src/core/tactics/，與地城 turn/ 平行。橋樑：TacticsBattle : Node。

戰棋 · 排程

ActionBar

ToME4 行動值模型。kCtToAct=1000。

advance()

每 tick 所有單位 ct += speed，第一個 ct >= 1000 者出手。平手取 ct 高者，再平手取加入序在前——確定性無亂數。

consume()：不歸零

出手後 ct -= 1000。溢出保留讓快角可連動兩次——這正是行動值模型的手感來源。

forecast(n) 在 ct 複本上模擬 n 步，不碰真實 ct——行動條 UI 預覽用。

戰棋 · 移動

可達集

四方向 BFS，每步固定 1。牆與其他單位佔格皆不可通行——不能穿不能停。

戰棋 · 結算

apply_tactics_action

只驗證幾何合法性（可達/射程/敵隊），不管子狀態——那是 Battle 的職責。

指令驗證事件
MoveTo(dst)dst 在可達集內Moved / Rejected
Attack(target)在 attack_range 內且敵隊Attacked + UnitDied（致死）
Wait——

戰棋 · AI

decide_tactics 選格排序鍵

依序比對
1 deficit = max(最近敵人距離 − attack_range, 0) 越小越好 2 nearest = 到最近敵人距離 越大越好 └ 關鍵：進射程就別再靠近，否則遠程送死 3 steps = 走幾步 越小越好

戰棋 · 回合

Battle 子狀態機

一個單位的回合：移動一次（可選）→ 行動一次（攻擊/Wait）。可先移動再攻擊，不可攻擊後再移動。攻擊即結束回合。

死亡單位由 Battle 從行動條移除並 destroy。前端 tactics_view.gd 靠 _seen_units 快照仍能叫出死者名字。
